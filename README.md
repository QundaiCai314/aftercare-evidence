# aftercare-evidence 1.0.0

售后凭证整理与补充指导 Skill：核对获准真实文件、指导补拍、整理事实说明并输出 EvidenceBundle。

## 下载与使用

- `aftercare-evidence-1.0.0.zip`：可加载 Skill 包，解压后将 aftercare-evidence 文件夹放入技能目录。
- `aftercare-evidence-1.0.0-full.zip`：完整工程，包括源码、接口样例、合成资料、测试结果及未生效契约提案。
- `测试报告.md`、`契约修订提案.md`：验证范围与当前限制。
- `SHA256SUMS.json`：上传文件摘要。

## 已实现与验证

支持单帧 JPEG/PNG 检查、JPEG 压缩及直角方向修正，保留原件。Python 3.10+，图片处理需 Pillow；工程校验另需 jsonschema/PyYAML。未实现自动裁剪、遮挡、PDF/视频处理、生产上传。

22项真实文件处理检查、42项离线来源/版本/授权/核对绑定检查通过；11组主结构检查及4项候选记录结构检查。独立模型进行了两轮各22例测试及5例定向回归，原始问题与限制保留，不把结构正确当作行为全部通过。

中央契约仍为1.0.0，核对绑定与正式上传链路尚未接通。材料核对不是上传授权；契约修订为评审提案。

## 发布副本说明

仅包含合成业务数据。不包含本机安装记录、机器环境路径或缓存。本机路径前缀统一为 `LOCAL_USER_HOME`；源文件摘要保留用于溯源，发布文件另有新的摘要清单。跨机器复跑上游集成前需将来源路径配置为本地对应版本，不把本地绝对路径当成可移植依赖。发布副本仅做路径脱敏，未重新执行整套模型测试。

完整工程中的安装状态说明属于原始交付记录；本仓库下载不自动安装或部署运行时。未另行指定开源许可证。
